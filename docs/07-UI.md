# 07 — UI: Necropolis (Costume Contest)

> Gate A / Gate D artefact. §1–4 are written before any screen; §5 onwards is added only when the sample is measured.

## 1. Style preset: *Nocturne cemetery*

One place, one hour: a hillside graveyard at 2 a.m., lit only by a low moon and whatever candles the visitors bring.

| Token | Value | Use |
|---|---|---|
| `--ink-0` | `#05070d` | page, deepest shadow |
| `--ink-1` | `#0a0e15` | panels, cards |
| `--bone` | `#e8e2d2` | primary text, engraving |
| `--bone-dim` | `#b9b3a4` | body copy |
| `--bone-faint` | `#8c887c` | labels, metadata |
| `--ember` | `#e8a33d` | the only accent: candles, focus, the selected grave |
| `--moss` | `#7f9a72` | moss on stone, never as a UI colour |
| `--line` | `rgba(232,226,210,.14)` | hairline rules |

- **Type**: `Cormorant Garamond` (display, engraving, numbers) + `Plus Jakarta Sans` (UI). Six sizes only: 12 / 13 / 16 / 18 / 28 / 38–64.
- **Rules**: 1px hairlines, no rounded cards above 10px, no drop shadows except the panel. Amber is a light source, not a decoration: at most one amber object per screen.
- **Motion**: fog drifts at 6–12 px/s; candles flicker at 9 Hz with ±12 % amplitude; camera eases at 0.08 per frame. All motion stops under `prefers-reduced-motion`.

## 3. One memory point

**The graveyard is made of your own repositories, and the moon is the only light.** Everything else in the interface is allowed to be quiet so that this one image survives a 3-second glance.

## 4. Main screen specification

- **Canvas**: full viewport, virtual 1600×900, DPR capped at 2. Three rows of graves, scales 0.8 / 1.02 / 1.3; 14–100 graves.
- **Sky**: 0–520 px; moon at (1176, 186) r=110 with a 380 px halo; 190 stars; 4 drifting cloud bands.
- **Ground**: from y=520; stone wall at y=514; 220 grass tufts; fog band at y=560–880.
- **Grave**: 72×96 base; six states (alive / fading / dormant / dead / forgotten / entombed); candle only on alive + fading; diagonal seal bar on entombed; three silhouettes (round arch, gothic arch, cross finial).
- **Text on stone**: name ≤ 19 chars at 10.4–13.6 px Cormorant, years at 7.4 px; hover lifts the stone 4 % and outlines it in amber.
- **HUD**: wordmark left; handle + grave count right; legend as a horizontal strip under the wordmark; hint bottom-centre.
- **Panel**: 432 px, right side, full height; name 38 px; epitaph in 22 px italic; vitals as a 2-column hairline grid; revival number 46 px.
- **Gate**: centred card, 600 px; h1 56–104 px; one input + one amber button.
- **Empty / error states**: inline, 16 px, never a toast.

## 5. Recorded exceptions and known weaknesses

Amber is a light source, not a decoration — but a lit graveyard has more than one flame. The exceptions, kept deliberately:

1. **More than one amber object on the graveyard screen**: the selected grave outline, the candle flames on living graves and the primary button. Each is a light source; none is decorative chrome. Every other accent is suppressed.
2. **Shadows outside the panel**: the obituary modal and the hover card use a drop shadow to separate themselves from the scene. Both are overlays, not page furniture.
3. **46px revival number** sits inside the 38–64 display band; it is a display figure, not body copy.
4. **Stone names at 10–14px**: the name is engraved text on a 3D object, not UI copy; the full name is always available in the hover card and the accessible list. Body copy elsewhere never goes below 16px.

A Kiro reviewer agent flagged 1, 2 and 3 as violations in `proof/kiro-review.log`; the type-scale findings it raised (15px, 26px) were fixed, and these three are documented here as intentional.
